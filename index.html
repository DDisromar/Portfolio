Automação com IA
⚡ Projeto em Produção · Oparks Travel
Invoice Automation — Pipeline Inteligente com IA
Automação end-to-end de processamento de faturas. O pipeline lê arquivos do SharePoint, usa IA (Claude API) para validar e cruzar dados, aciona aprovação humana por e-mail, atualiza banco de dados e registra tudo no QuickBooks com geração de PDF automática — orquestrado via N8N.
N8N Claude API SharePoint QuickBooks Outlook Microsoft Graph API
Fluxo do pipeline — N8N
Detalhamento das etapas
▶
Trigger — Monitoramento SharePoint
Detecta automaticamente novos arquivos Excel enviados para pasta específica no SharePoint e inicia o pipeline.
SharePointN8N Trigger
1
Leitura de Arquivos
Lê 6 arquivos Excel via Microsoft Graph API: fatura do fornecedor, invoice, vendas, cancelamentos, banco de dados e Cangooroo.
Microsoft Graph APIExcel Online
2
Processamento com IA — Claude API
Todos os dados são enviados para o Claude (Anthropic API). A IA cruza as informações, valida inconsistências e retorna JSON estruturado com as modificações necessárias.
Claude APIHTTP RequestJSON
3
Atualização de Arquivos
Aplica as modificações retornadas pela IA nos arquivos de invoice e vendas via Microsoft Graph API.
Microsoft Graph APIExcel Online
4
E-mail de Aprovação
Envia e-mail automático ao colaborador com botão de aprovação vinculado a webhook — notifica que os arquivos estão prontos para revisão.
OutlookWebhook
5
Aguarda Aprovação Humana
Pipeline pausa e aguarda o colaborador clicar no botão de aprovação. Human-in-the-loop antes de gravar no banco.
Webhook NodeN8N Wait
6
Atualização do Banco de Dados
Grava todos os dados na aba correta do Excel de banco de dados, inserindo após a última linha preenchida.
Microsoft Graph APIExcel Online
7
Envio da Fatura por E-mail
Envia automaticamente o arquivo de invoice como anexo para o destinatário final.
Outlook
8
Integração QuickBooks + PDF
Consulta cliente no QuickBooks, insere dados da fatura, gera PDF automaticamente e salva na pasta designada no SharePoint.
QuickBooks APISharePointPDF
